Contacts

The Contacts Screen is where you manage all the people and businesses you transact with. Contacts help you track who you're paying money to or receiving money from, making it easy to see your spending patterns with specific stores, companies, or individuals over time.

Accessing the Contacts Screen

You can access the Contacts Screen by:

  • Tapping More in the bottom navigation bar, then tapping Contacts under the Advanced Features section

Understanding Contact Categories

Contacts are organized into categories to help you find and group them logically. The available categories are:

  • Stores - Physical retail locations where you shop
  • Online Stores - E-commerce websites and online retailers
  • Cafes & Restaurants - Places where you eat and drink
  • Individuals - People you transact with (friends, family, freelancers)
  • Companies & Organizations - Businesses and organizations
  • Healthcare - Doctors, hospitals, pharmacies, and health services
  • Investments - Brokerages, investment platforms, and financial institutions
  • Charity - Non-profits and charitable organizations
  • Other - Anything that doesn't fit the categories above

Each category displays its own icon and groups all related contacts together.

Screen Layout

Contact Category Cards

The main area displays your contacts organized into category cards. Each card shows:

  • Category icon (on the left) - A visual identifier for the category type
  • Category name - The name of the category (e.g., "Stores", "Individuals")
  • Contacts within - All contacts belonging to that category, listed alphabetically

Individual Contacts

Within each category card, contacts are listed showing:

  • Avatar - A circle with the contact's first letter
  • Contact name - The name you gave the contact (e.g., "Amazon", "John Smith")
  • Description - Any notes you added about the contact (if provided)
  • Total amount - The net transaction total with this contact for the selected period
    • Positive amounts (you received money) show with a plus sign
    • Negative amounts (you paid money) show the amount spent
    • The period can be configured in settings (current month, current year, or all time)
  • Menu button (three dots) - Opens contact actions

Top Bar Actions

The top bar contains several action buttons:

Search Button

Tap the search icon to reveal a search bar. You can search contacts by:

  • Contact name
  • Contact description

The list filters in real-time as you type. Tap the search icon again to close the search bar.

Add Contact Button (+)

Quickly create a new contact. Opens the Add Contact screen.

More Options Menu (three dots)

Tap to access additional options:

  • Settings - Configure contact-related preferences
  • Merge Contacts - Combine existing contacts into one
  • Archive - View and manage archived contacts

Contact Actions

Tapping a Contact

Tap any contact to view all transactions involving that contact. This opens a filtered transaction list showing:

  • All income and expenses with this contact
  • The transaction history over time
  • Date range matching your totals period setting

Long-Pressing a Contact (or Tapping the Menu Button)

Opens a menu with these options:

  • Transactions - View all transactions with this contact
  • Trends - See a year-by-year breakdown of your transaction totals with this contact
  • Analytics - View charts and detailed analytics for this contact's transactions (only available if the contact has transactions)
  • Edit - Change the contact's name, category, or description (only available if the contact has transactions)
  • Archive - Hide the contact from the main list (keeps all history)
  • Delete - Permanently remove the contact (only available if the contact has no transactions)

Note: You cannot delete a contact that has transactions. Archive it instead to hide it while preserving your financial history.

Adding a New Contact

When adding a new contact, you'll fill in:

Required Fields

  • Name - A unique name for the contact (e.g., "Starbucks", "Dr. Smith", "Netflix")

Optional Fields

  • Category - Which category this contact belongs to (defaults to "Stores")
  • Description - Notes about the contact (e.g., "Dentist on Main Street", "Monthly subscription")

Duplicate Check: The app will alert you if a contact with the same name already exists, ensuring each contact has a unique name.

Tap the top-right checkmark to save and return to the previous screen.

Editing a Contact

When editing a contact, you can change:

  • Name - Update the contact's display name
  • Category - Move the contact to a different category
  • Description - Add or update notes about the contact

Merging Contacts

Open More → Contacts, tap the three dots in the top bar, then Merge Contacts. This action is available without Pro, including when the list is empty or only one contact exists; completing a merge requires at least two distinct existing contacts and an active target.

  1. Read the backup reminder. Create Backup Now opens the backup screen. Return with Back to continue with your selections preserved. Opening backup hides the reminder for this visit; it does not confirm that a backup was created.
  2. Tap Contacts to Merge. This opens the usual Contacts selection page. Both the source and target pickers use this title. Contacts are grouped by contact category and sorted alphabetically within each group. Active and archived entries appear, with an archive icon beside archived entries. Tap a row to select or deselect it; selected rows are highlighted and show a checkmark. Tap the search icon in the top bar to search names or descriptions. The selected-item strip stays visible while filtering: tap an item in the strip to remove it, or the × at the right to clear the selection. Closing search clears the search text but preserves selections. Selection changes apply to the merge form immediately, including removing or clearing selections. Use Back to return with your current selection preserved; there is no approval checkmark in the picker. Selecting items alone does not perform a merge.
  3. Tap Target Contact and then tap the existing contact you want to keep. This field is disabled until a source is selected. Only active contacts appear as targets. The target may also be in the source selection, but at least one other source is required. Clearing all sources also clears the target.
  4. Tap the checkmark at the top right of the merge form. Missing sources or a missing target show a validation message; selecting only the target as a source is also rejected.
  5. Review the confirmation, which shows the number of sources that will be deleted (excluding the target) and the target's name. Cancel returns to the form with selections preserved. Merge Contacts confirms the permanent merge. While it runs, the form shows a progress indicator and Back is disabled. Success returns to the Contacts list with a success message and refreshed totals.

The merge affects all dates, including historical and planned transactions, favourites, and recurring transactions, even inactive schedules. Source contacts are deleted. The target keeps its name, description, and contact category. Transaction amounts, dates, descriptions, accounts, and recurring schedules stay the same. There are no extra-description or extra-tag options on this form.

All transactions using a source contact now use the target contact. Remembered contact choices for statement imports also change to the target, so future matching imports can use it.

Saved Sets replace source contact selections with the target in both included and excluded filters, removing repeated selections within each list. This can change results: a filter now covers the combined contact's transactions. If the merge leaves the target both included and excluded, exclusion still applies; review the Saved Set filters afterward.

If a picker has no matching entries, it shows the usual contact search empty state. Clear or close search, or return with Back. Use + in either picker to create a contact with the usual Add form. Saving from the source picker selects the new contact immediately and keeps the picker open; use Back to return to the merge form. Saving from the target picker selects the new target and returns to the merge form. Back from Add without saving preserves the existing selection. Newly created contacts remain available even if you later cancel the merge. Pickers load the current list when opened. If loading fails, return and reopen the picker. If a merge fails, an error message appears and selections remain. Correct unavailable sources or targets by reopening the relevant picker; a target must be active.

This action cannot be undone from the merge screen. Back before confirmation does not merge or delete anything; newly created entries remain; returning later starts with empty selections. A backup made before merging is the recovery option if you need the original records.

Contact Settings

Access settings from the More Options menu. Available settings include:

Show on transaction creation

Controls whether the payment recipient/sender field appears when creating transactions. Turn this off if you don't use contacts and want a simpler transaction form.

Contact Summary Period

Configure which time period is used to calculate the totals shown next to each contact (labeled "Contact Summary Period" in the app):

  • All Time - Shows the total of all transactions with each contact since you started using the app
  • Current Month - Shows only this month's transaction totals
  • Current Year - Shows this calendar year's transaction totals

This setting also affects the initial date range when you tap a contact on the main Contacts screen to view their transactions.

Archive

The Archive stores contacts you've hidden from your main list. Archiving is useful for:

  • Contacts you no longer transact with
  • Temporary contacts you don't need visible
  • Keeping your main contact list clean and focused

Viewing the Archive

Access the archive from the More Options menu. Here you'll see all archived contacts organized by category, just like the main screen.

Archive Actions

For archived contacts, you can:

  • View Transactions - See the contact's transaction history (full history, not limited by the Contact Summary Period setting)
  • View Trends - See year-by-year totals for this contact
  • Restore - Bring the contact back to your main list (only available if the contact has transactions)
  • Delete - Permanently remove the contact (only available if the contact has no transactions)

Empty States

No Contacts Yet

If you haven't created any contacts, you'll see a helpful message with an "Add Contact" button to get started.

No Search Results

If your search doesn't match any contacts, you'll see a message indicating no contacts were found, along with an option to add a new contact.

Tips for Using Contacts

  1. Be consistent with naming - Use the same spelling for the same business or person to keep your data clean

  2. Choose the right category - Proper categorization makes it easier to find contacts and understand your spending patterns

  3. Use descriptions wisely - Add helpful notes like location, account numbers, or what you typically buy there

  4. Check the Contact Summary Period - Make sure you understand which time period the displayed totals represent (Settings → Contact Summary Period)

  5. Archive instead of delete - If you stop transacting with a contact, archive it to keep your history intact

  6. Review analytics - Use the Analytics option (when the contact has transactions) to see detailed charts and breakdowns of your spending with specific contacts

  7. Use search for quick access - When you have many contacts, the search feature helps you find what you need quickly

  8. Link contacts to transactions - When adding transactions, assign them to contacts to build useful spending insights over time

  9. Regular cleanup - Periodically review your contacts and archive any you no longer use to keep your list manageable
