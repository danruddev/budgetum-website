Transactions for an account, category, contact, or tag

The Entity Transactions Screen shows all transactions related to a specific item—whether that's an account, budget category, budget section, contact, or tag. This screen provides a focused view of your financial activity filtered to one particular area, helping you understand your spending patterns and track transactions for specific purposes.

Accessing the Entity Transactions Screen

You can access this screen by tapping on:

  • An account from the Accounts Screen
  • A budget category from the Budget Screen
  • A budget section from the Budget Screen
  • A contact from the Contacts list
  • A tag from the Tags list

Screen Layout

Title Bar

The title bar displays:

  • Back button (left) - Returns to the previous screen
  • Entity name - The name of the account, category, section, contact, or tag you're viewing
  • Analytics icon (pie chart) - Opens Analytics & Reports starting with this entity. Further drill-down selections retain the original entity filter; the Transactions option inside analytics shows the resulting intersection.
  • Search icon - Opens transaction search filtered to this entity

Period Picker

Below the title bar, you'll find the period picker that lets you select the date range for viewing transactions.

Actions:

  • Tap the period to open the period selection options where you can choose:
    • This month
    • Last month
    • This year
    • Last year
    • All time
    • Custom date range
  • Calendar icon (left side) - Opens the Day Transactions view where you can browse transactions on a calendar, day by day

The period picker may also show balance information when viewing an account.

Summary Card

The Summary Card at the top shows financial totals for the selected period.

For Accounts

When viewing an account, the summary shows:

  • Inflow - Total money coming into this account (deposits, transfers in)
  • Outflow - Total money leaving this account (withdrawals, transfers out)

You can expand the summary to see detailed breakdowns. The expanded view shows (in order):

  • Regular income and regular expenses (first row)
  • Transfers received and transfers sent (second row)
  • Balance increases and balance decreases (third row)
  • Opening balance and closing balance for the period (at the bottom)

For Categories, Sections, Contacts, and Tags

The summary shows:

  • Income - Total income transactions for this entity
  • Expenses - Total expense transactions for this entity

Expense Type Breakdown

For sections, contacts, and tags, you can toggle to see expenses broken down by category type:

  • Needs - Essential expenses
  • Wants - Non-essential/discretionary expenses
  • Savings - Savings contributions

Tap the card to toggle between the standard view and the expense type breakdown.

History and Upcoming Tabs

When you have both past transactions and future scheduled transactions for the entity, the screen displays two toggle buttons:

History Tab

Shows all transactions from today and earlier, sorted with the most recent transactions first.

Upcoming Tab

Shows all future transactions (scheduled, recurring, or planned), sorted with the soonest transactions first.

Tab Information:

  • Each tab displays the total income and expenses for that section
  • Income is shown in the income color (from your Income budget section) with a "+" prefix
  • Expenses are shown in red with a "-" prefix
  • Tap a tab to switch between History and Upcoming views

Note: If you only have past transactions or only have future transactions, the tabs won't appear—the screen will automatically show whichever section has data.

Transaction List

Transactions are grouped by date with clear date headers. Each date section shows all transactions that occurred on that day. On account and set views, transactions from the same receipt or the same contact on that day may be grouped together. Category, section, contact, tag, category-type, and contact-type views list each receipt item on its own.

Transaction Display

Each transaction shows information relevant to the entity you're viewing:

  • Category icon (when not viewing a category/section) - The icon of the budget section
  • Category name - The budget category this transaction belongs to
  • Amount - The transaction amount with color coding:
    • Income color (from your Income budget section) with "+" prefix = Income
    • Section color = Expenses

What's Hidden

Depending on what entity you're viewing, some information is hidden since it would be redundant:

  • Viewing an account - The account badge is hidden (you already know the account)
  • Viewing a category - The category name and icon are hidden
  • Viewing a section - The section icon is hidden
  • Viewing a contact - The contact badge is hidden
  • Viewing a tag - The current tag is hidden (other tags still appear)

Additional Details

Transactions may also display:

  • Receipt icon - Shown after the row title when the transaction belongs to a receipt. The title is the category name, or the description when you are viewing a category and the transaction has a description. Category, section, contact, tag, category-type, and contact-type lists do not group receipt items, so this icon is how you can tell a line is part of a receipt.
  • Recurring icon (↻) - Indicates a recurring transaction
  • Question mark icon (?) - Indicates confirmation is required
  • Swap icon (↔) - Indicates a transfer between accounts
  • Contact badge - Shows the associated contact (when not viewing a contact)
  • Account badge - Shows the account used (when not viewing an account)
  • Description - Any notes on the transaction
  • Tags - Hashtags for additional categorization

Running balance (account views)

When viewing an account, each row can show a muted running balance directly under the transaction amount. That value is the account balance after that row in the ledger (history walks from the period-end balance backward; upcoming/forecast walks forward from today’s posted balance). Running balance appears only on account entity lists, not on category, section, contact, or tag views.

Preview Transactions

Future transactions from recurring templates appear slightly faded to indicate they are previews of upcoming scheduled transactions. This also applies to Sets: only occurrences matching the set's include/exclude conditions and amount limits appear, and Upcoming totals include them. When opened from the Sets block on Budget, the initial dates come from the selected budget period. Budget's Include future transactions setting affects Budget amounts only; this screen still shows matching saved transactions and recurring previews using its usual History and Upcoming views.

Transaction Types

Regular Transactions

Standard income or expense transactions linked to a budget category.

Transfers (Account View Only)

When viewing an account, you'll see transfers involving that account:

  • A swap icon (↔) indicating a transfer
  • The other account involved in the transfer
  • The transfer amount

Balance Adjustments (Account View Only)

Manual adjustments to the account balance:

  • "Balance Increase" or "Balance Decrease" as the title
  • The adjustment amount

Transaction Actions

Tap a Transaction

For regular transactions: Opens the Edit Transaction screen where you can modify all details.

For preview/recurring transactions: Opens options to:

  • Confirm the transaction
  • Skip this occurrence
  • Modify the amount or details

For confirmation-required transactions: Opens a confirmation dialog with options to confirm, skip, or edit.

For transfers: Opens the Edit Transfer screen.

For balance adjustments: Opens the Edit Balance screen.

Long-Press a Transaction

Long-pressing a transaction (except preview and confirmation-required ones) opens the same quick actions as on Transactions: edit, duplicate, delete, and transform to receipt when that expense can become a receipt. If the transaction already belongs to a receipt, Edit receipt opens that receipt with all of its items, including items that are not in this category, section, contact, or tag.

Adding New Transactions

For Account Views

A floating action button (+) appears at the bottom center. Tapping it opens a menu with options:

  • Add Transaction - Record a new income or expense using this account (available for foreign-currency accounts as well as main-currency accounts)
  • Add Receipt - Add a receipt and create transactions using this account (only for accounts in your main currency; hidden for foreign-currency accounts)
  • Transfer Between Accounts - Move money to or from this account
  • Increase Balance - Add money to this account without creating an income transaction
  • Decrease Balance - Remove money from this account without creating an expense transaction

For Category Views

A floating action button (+) appears at the bottom center. Tapping it opens the Add Transaction screen with this category pre-selected.

For Other Views

Contacts, sections, and tags do not have a floating action button since transactions are created through the main Transactions screen or Budget screen.

Loading More Transactions

The screen initially shows a limited number of transactions for faster loading:

  • History tab - Shows 100 transactions at a time (for periods longer than 45 days)
  • Upcoming tab - Shows 90 days of future transactions at a time

"Show More" Button

When there are additional transactions to display, a "Show More" button appears at the bottom of the list. Tap it to load more transactions.

Empty State

If there are no transactions for the selected entity and period, the screen displays:

  • A receipt icon
  • A message indicating no transactions exist for this period

Different Views Explained

Account Transactions View

When you tap an account from the Accounts screen, you see:

  • All transactions where this account was used
  • Transfers involving this account
  • Balance adjustments for this account
  • The inflow/outflow summary helps you understand cash flow through this account

Use this to: Track spending from a specific card, review bank account activity, or reconcile balances.

Category Transactions View

When you tap a budget category, you see:

  • All transactions assigned to this category
  • How much you've spent in this category for the period

Use this to: Review all grocery purchases, track entertainment spending, or analyze any specific category.

Section Transactions View

When you tap a budget section, you see:

  • All transactions from all categories within this section
  • The combined income or expenses for the entire section

Use this to: Get a broader view of spending areas like "Food & Dining" or "Transportation."

Contact Transactions View

When you tap a contact, you see:

  • All transactions associated with this person or business
  • Your complete transaction history with this contact

Use this to: See how much you've spent at a particular store, track payments to a service provider, or review transactions with a specific person.

Tag Transactions View

When you tap a tag, you see:

  • All transactions that have this tag applied
  • Spending patterns for this specific tag

Use this to: Track project expenses, vacation spending, or any custom grouping you've created with tags.

Tips for Using This Screen

  1. Use date ranges strategically - Select "All Time" to see complete history, or narrow to specific months for focused analysis

  2. Check both tabs - Review History to see what happened and Upcoming to see what's scheduled

  3. Use Analytics - Tap the pie chart icon for visual charts and deeper insights about this entity

  4. Use Search - The search function helps you find specific transactions within this entity's history

  5. Expand account summaries - When viewing accounts, tap the Summary Card to see detailed breakdowns of all transaction types

  6. Review expense types - For sections, contacts, and tags, toggle the expense breakdown to see needs vs. wants vs. savings

  7. Add transactions directly - When viewing accounts or categories, use the floating action button to quickly add transactions with that entity pre-selected
