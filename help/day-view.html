Day view

The Day Transactions Screen provides a focused view of your transactions for a specific day, with an integrated calendar for easy navigation between dates. This screen helps you review daily spending patterns and see exactly what happened on any given day.

Accessing the Day Transactions Screen

You can access the Day Transactions Screen by:

  • Main Transactions screen — Tapping the calendar icon in the app bar
  • Account, category, or other entity — When viewing transactions for an account, category, section, contact, or tag, tapping the calendar icon in the period bar (the bar below the header that shows the date range) opens the Day Transactions Screen for that same entity

Screen Layout

Top Bar (Header)

The top bar stays visible while you scroll. It displays the currently selected date and provides quick navigation controls.

Elements:

  • Left Arrow (<) - Navigate to the previous day
  • Selected Date - Shows the current date in a friendly format (e.g., "Today", "Yesterday", "Mon, Jan 20")
  • Daily Total - Displays the net total for the selected day (income minus expenses). Shown only when the day has transactions or when in selection mode with at least one transaction selected.
  • Right Arrow (>) - Navigate to the next day
  • Selection Mode Button - Toggle multi-select mode for transactions (checkmark icon). Hidden for future dates.

Actions:

  • Tap the date or calendar icon beside it to scroll back to the calendar at the top of the page. This preserves the selected day and any selected transactions.
  • Tap the arrows to move forward or backward one day at a time

Daily Total Display

When the day has transactions (or in selection mode), below the date you'll see:

  • A positive total (with + prefix) when income exceeds expenses
  • A negative total when expenses exceed income
  • The total updates in real-time as you navigate between days
  • In selection mode, the total shows the sum of only the selected transactions (for an account, the net impact on that account)

Calendar View

The calendar is shown at the top of the page when you open this screen. It and the selected day’s transactions scroll together: swipe up to move past the calendar and read more transactions, or scroll back to the top to choose another date. Tapping the date or its calendar icon in the fixed header also returns to the calendar. There is no calendar hide/show toggle.

Month Navigation

At the top of the calendar:

  • Left Arrow (<) - Go to the previous month
  • Month and Year - Tap to open a month/year picker for faster navigation
  • Right Arrow (>) - Go to the next month

Calendar Grid

A row of weekday labels (e.g. Mon, Tue, …) appears above the grid. The calendar displays only the current month’s days with the following features:

Day Tiles:

  • Each day shows the day number
  • Days with transactions display daily income (in the income color with + prefix) and expenses (in red with - prefix)
  • The selected day is highlighted with a colored border and subtle background
  • Today's date has a special border highlight
  • Future days appear slightly faded
  • Empty cells before the first day of the month are left blank (other months’ days are not shown)

Actions:

  • Tap any day in the current month to select it and view its transactions
  • Selecting a day updates the header, daily total, and transactions below without closing the calendar or automatically scrolling away from it. It exits selection mode and clears any selected transactions.

Month/Year Picker

When you tap the month name in the calendar header, a picker opens allowing you to:

  • Quickly jump to any month
  • Navigate between years
  • See which months have transaction data

Transaction List

Below the calendar, you'll see all transactions for the selected day.

Transaction Display

Each transaction shows:

  • Category icon - Visual indicator of the transaction category
  • Category name - The budget category this transaction belongs to
  • Amount - The transaction amount with appropriate color coding:
    • Green with + prefix for income
    • Category section color for expenses

Additional Details

Transactions may also display:

  • Receipt icon - Shown after the category name, or after the description when that is the row title, when the transaction belongs to a receipt and is listed on its own. Grouping follows the list you opened this day from: account and set days can still fold several receipt items into one group, and that group shows the receipt icon after the category name when every item uses the same category.
  • Recurring icon (↻) - Indicates a recurring transaction
  • Confirmation icon (?) - Indicates confirmation is required
  • Transfer icon (↔) - Indicates a transfer between accounts
  • Contact badge - Shows associated person or business
  • Account badge - Shows which account was used
  • Description - Any notes added to the transaction
  • Tags - Hashtags for additional categorization

Grouped Transactions

Depending on context, transactions may be grouped by:

  • Receipt - Multiple items from the same receipt shown together
  • Contact - Transactions with the same person or business grouped

Empty State

If there are no transactions for the selected day:

  • A receipt icon is displayed
  • A “No results found” message is shown

Selection Mode

The Day Transactions Screen includes a powerful selection mode for analyzing multiple transactions at once.

Activating Selection Mode

Tap the checkmark icon in the top-right corner of the header to enter selection mode.

Using Selection Mode

When in selection mode:

  • Tap individual transactions to select or deselect them
  • Tap a group header to select or deselect all transactions in that group
  • Selected transactions show a checkmark indicator
  • The header total updates to show the combined total of only selected transactions

Viewing Selected Totals

While in selection mode, the daily total in the header changes to show:

  • The combined amount of all selected transactions
  • This helps you quickly calculate subtotals for specific purchases or activities

Exiting Selection Mode

Tap the checkmark icon again to exit selection mode and clear all selections.

Note: Selection mode is not available for future dates (dates that haven't occurred yet).

Transaction Types and Actions

Tapping Transactions

Different transaction types have different behaviors when tapped:

Regular Transactions (Income/Expenses): Opens the Edit Transaction screen where you can modify all details.

Recurring Preview Transactions: For transactions that are previews of upcoming recurring entries, tapping opens options to:

  • View the recurring template
  • Confirm the transaction early
  • Skip this occurrence

Confirmation-Required Transactions: For scheduled transactions requiring your approval, tapping opens a confirmation dialog with options to:

  • Confirm the transaction
  • Skip this occurrence
  • Edit before confirming

Transfers: Opens the Edit Transfer screen to modify transfer details.

Balance Adjustments: Opens the Edit Balance screen to modify the adjustment.

Long-press a transaction (except previews and confirmation-required ones) for edit, duplicate, and delete. If it belongs to a receipt, Edit receipt opens that receipt with all of its items.

Adding New Transactions

The floating action button(s) at the bottom of the screen let you quickly add new entries. The available options depend on the context you're viewing:

Global View (All Transactions)

A single Add Transaction button opens the Add Transaction screen with the selected date pre-filled. To create a receipt from there, use expense mode and tap the split icon next to the Category field.

Account View

A single + button opens a menu with options to:

  • Add Transaction - Record a new expense or income for this account (available for foreign-currency accounts as well as main-currency accounts)
  • Add Receipt - Add or enter a receipt for this account (only for accounts in your main currency; hidden for foreign-currency accounts)
  • Transfer Between Accounts - Create a transfer involving this account
  • Balance Increase - Add a positive balance adjustment
  • Balance Decrease - Add a negative balance adjustment

Category View

A single + button opens the Add Transaction screen with:

  • The selected category pre-filled
  • The selected date pre-filled

Context Awareness

The Day Transactions Screen adapts based on where you access it from:

From the Main Transactions Screen

  • Shows all transactions across all accounts and categories
  • Both floating action buttons (receipt and add) are available

From an Account

  • Shows only transactions for that specific account
  • Account-specific add options are available
  • Account badges may be hidden since you're already viewing one account

From a Category

  • Shows only transactions for that specific category
  • Add transaction opens with the category pre-selected

From a Contact, Tag, or Section

  • Shows only transactions related to that entity
  • No floating action button is shown; you cannot add transactions from this screen when viewing by contact, tag, or section

Visual Indicators

Day Tile Colors

In the calendar grid:

  • Income color - Income totals for that day (typically green; follows budget section color)
  • Red amounts - Expense totals for that day
  • Highlighted border - Currently selected day or today
  • Faded appearance - Future dates

Transaction Colors

In the transaction list:

  • Income color with + - Income transactions (typically green; follows budget section)
  • Section color - Expense transactions (matches budget section)
  • Faded appearance - Preview/scheduled transactions not yet confirmed

Tips for Using the Day Transactions Screen

  1. Quick date navigation - Use the left/right arrows to quickly check adjacent days
  2. Use the calendar for jumping - Tap the date in the header to return to the calendar, then choose any day, especially when looking at historical data
  3. Check daily patterns - The calendar's income/expense indicators help you spot spending patterns at a glance
  4. Selection mode for subtotals - Use selection mode to quickly calculate the total for specific purchases or categories
  5. Future planning - View future dates to see upcoming scheduled and recurring transactions
  6. Add transactions on the right date - When viewing a specific date, new transactions automatically use that date
  7. Month picker for long jumps - Tap the month name to quickly jump to months far in the past

Navigating Back

Tap the X (close) button in the top-left corner to exit the Day Transactions Screen and return to the previous screen.
